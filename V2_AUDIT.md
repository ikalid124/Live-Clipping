## Remaining limits

Chat cannot distinguish coordinated accounts that behave exactly like independent viewers. A quiet, funny exchange with no audience signal may never become a candidate. The score is heuristic. An archive can expire between lookup and playback, and playback permission depends on the viewer. The archive cache is considered fresh for ten minutes. Community matching uses creation time when archive timing is unavailable. A channel's reported stream start and archive creation time can differ; offsets remain estimates. Continuous high-volume field performance and end-to-end external delivery remain unmeasured.

For future opt-in audio detection, accept time-stamped speech activity or laughter intervals from an authorized source and correlate them with the same event window. A local transcription adapter could add dialogue excerpts and their source offsets as a separate evidence type with its own retention setting. The first comparison should measure incremental recall on labeled quiet scenes before using either input to send alerts.
